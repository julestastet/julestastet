## 🔬 Featured projects

- 🔥 **[Predicting Critical Import Concentration in French Trade](https://github.com/julestastet/import-concentration-ml)** — ML early-warning system for supply-chain vulnerability: classifying one year in advance which French import markets will become critically concentrated (HHI > 0.25). BACI/CEPII panel 1996–2024, ~100k product-year observations, temporal cross-validation, **AUC 0.970** on holdout. *R (tidyverse, glmnet, randomForest, arrow).*

- 📊 **[Telecom Data Analysis & Economics](https://github.com/julestastet/Telecom-DataAnalysis_Economics)** *(contributor)* — economics research data pipeline: scraping author affiliations, extracting JEL codes from RePEc articles, database matching, R regressions and cluster analysis. *R + Python.*
